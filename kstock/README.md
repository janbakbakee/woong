# 국내주식 수급 추천 (kstock)

COT와 별개로 돌아가는 패키지. `cot/`를 import 하지 않고, 워크플로·동시실행 그룹도 따로(`kstock-daily`) 쓴다. 레포에 커밋하지 않고 텔레그램으로만 보낸다.

```
평일 07:47 KST (장 전) / 18:07 KST (장 마감)  — .github/workflows/kstock-daily.yml
 ├─ KIS 휴장일 조회 → 휴장이면 종료
 ├─ KIS 종목 마스터 → 보통주·정상거래·시총(코스피 3천억/코스닥 2천억↑)·전일 거래대금 10억↑
 ├─ 종목별 투자자매매동향(일별) → 필터 → 100점 점수
 ├─ 상위 12개: DART 공시 악재(유증·CB 등) 제외 + Google News 악재 헤드라인 감점
 └─ 상위 5개 → 텔레그램
```

| 영역 | 배점 | 내용 |
|---|---|---|
| 수급 | 40 | 5일 외국인+기관 ÷ 20일 평균 거래대금, 20일 누적 ÷ 시총, 쌍끌이 연속일(3~10일 최고), 연기금·투신·사모 비중 |
| 거래량·추세 | 25 | 거래량 배수(1.2~3배 최고, 5배↑ 과열), 20일선 위, 20>60일선, 60일 고점 근접 |
| 재무 | 20 | 영업이익 흑자, ROE (KIS 마스터 기준) |
| 뉴스·공시 | 15 | 악재 헤드라인 1건당 -5, DART 악재 공시는 제외 |

필터: 20일 평균 거래대금 50억↑, 5일 외국인·기관 각각 순매수 + 합계 코스피 50억/코스닥 20억↑, 당일 +15%↑·5일 +30%↑ 제외.
기준값은 `kstock/score.py` 상단 상수.

**Secrets**: `KIS_APP_KEY`, `KIS_APP_SECRET` (필수), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `DART_API_KEY` (선택 — 넣으면 다음 실행부터 자동 사용),
`KSTOCK_TELEGRAM_BOT_TOKEN` / `KSTOCK_TELEGRAM_CHAT_ID` (선택 — 국장 전용 봇/방. 없으면 COT 봇/방으로 전송)

로컬 실행: `python -m kstock.main --session close --dry-run`
