# 국내주식 수급 추천 (kstock)

COT와 별개로 돌아가는 패키지. `cot/`를 import 하지 않고, 워크플로·동시실행 그룹도 따로(`kstock-daily`) 쓴다.
텔레그램은 순위·한 줄 코멘트·진입 후보만, 근거(차트·수급표·점수·목표가)는 웹페이지 `docs/kstock/` (COT와 같은 GitHub Pages 사이트, 장 마감·장중 실행만 커밋).

```
평일 06:50(→07시 전후 도착) 장 전 · 14:35 장중 예비 · 18:07 장 마감 (KST) — .github/workflows/kstock-daily.yml
 ├─ KIS 휴장일 조회 → 휴장이면 종료 (조회 실패는 휴장으로 보지 않고 실패 알림)
 ├─ 코스피·코스닥 지수 일봉 → 기준일(최신 거래일) · 시장 신호등 🟢🟡🔴 · 상대강도 기준
 ├─ KIS 종목 마스터 → 보통주·정상거래·시총(코스피 3천억/코스닥 2천억↑)·전일 거래대금 10억↑
 ├─ 종목별 투자자매매동향(일별) → 기준일 불일치 제외 → 필터 → 100점 점수
 ├─ 시장별 상위 10개: DART 악재 공시 제외 + Google News 악재 헤드라인 감점
 ├─ 조건 통과 전체 후보 CSV(top_rank 포함)·메시지 원문 → Actions 아티팩트(90일, 백테스트용)
 ├─ [장 마감] TOP 종목 증권사 투자의견·목표가(최근 3개월, KIS) → docs/kstock/data/<기준일>.json
 │           → 최근 10거래일만 남기고 날짜 탭 페이지 생성 → 커밋 → Pages 배포
 ├─ 조건 통과 종목 중 진입 셋업(🅐 눌림 / 🅑 돌파) 판정 → 시장별 최대 3개, 위험 기반 비중·손절가 (signals.py)
 └─ 코스피 TOP 5 · 코스닥 TOP 5 + 🎯 진입 후보 → 텔레그램 2통 (페이지 커밋 뒤 전송, 장 전에는 미국 시장 한 줄)

[장 전 07:00] 전일 장 마감 기록(진입 후보·TOP·신호등) + 미국 시장 한 줄 — 분석을 다시 돌리지 않음
[장중 14:35] 전일 장 마감 조건 통과 종목만, Actions 캐시에 보관한 일봉 + 현재가 + 외인·기관 잠정 가집계(14:30)로 셋업 재판정
 → 웹페이지 최신 탭 위 노란 '⏱ 장중 예비 신호' 상자 (장 마감 때 자동 제거) → 신호 있을 때만 텔레그램
   (잠정 기관은 금투 포함, 거래량은 경과 시간으로 하루치 환산 — 확정치와 다를 수 있음)
```

⚠️ KIS 종목별 투자자 일별 API(`FHPTJ04160001`)는 **00:00~15:40에 조회 불가**(`OPSQ2001 TIME LIMIT`).
그래서 전체 분석은 장 마감(18:07)에만 하고, 장 전은 저장된 기록을, 장중은 캐시된 일봉(`work/rows.json`, 키 `kstock-rows-*`)을 쓴다.

진입 신호 (기존 100점 점수는 기준 모델로 그대로 두고 그 위에 얹음 — 모든 수치는 검증 전 가설):

| 항목 | 기준 |
|---|---|
| 🅐 눌림 | MA20 상승(5일 전 대비)·MA20>MA60, 최근 3일 저가 ≤ MA20+0.5ATR, 종가 ≥ MA20, 직전 3일 거래량 ≤ 0.8배, 3일 외인+기관 ≥ 0, 종가 위치 ≥60% 또는 전일 고가 돌파 → 손절 3일 최저가−0.3ATR |
| 🅑 돌파 | 돌파일 제외 직전 20일 고저폭 ≤20%, 종가 > 그 고점, 거래량 ≥1.5배(5배↑ 경고), 종가 위치 ≥70%·윗꼬리 <25%, 외인·기관 동시 순매수, 전일 ATR 이격 ≤2.5 → 손절 max(당일 저가, 박스 고점−1ATR) |
| 등급·시장 | A급 = 지수 대비 20일 +3%p↑. 🟢 A·B / 🟡 A만·위험 절반 / 🔴·악재뉴스 금지. 손절폭 8% 초과 무효 |
| 비중 | 거래당 위험 0.75% ÷ 손절폭, 종목당 최대 33% (`KSTOCK_CAPITAL` 있으면 수량까지) |
| 실행 | 장 마감 신호 → 다음 날 매수 구간 🅐 +1%·🅑 +2%, 시초가 🅐 +3%·🅑 +2%↑면 패스 / 장중 신호 → 15:20 동시호가·15:40 시간외 종가 |

| 영역 | 배점 | 내용 |
|---|---|---|
| 수급 | 35 | 기관 = 기관계 − 금융투자. 5일 외인+기관 ÷ 20일 평균 거래대금(12), 20일 누적 ÷ 시총(10, 만점: 시총 10조↑ 0.3%·2조↑ 0.6%·그 외 1%), 쌍끌이 연속 3~10일(8), 연기금·투신·사모 비중(5) |
| 거래량·캔들 | 25 | 거래량 배수(10: 1.2~3배 최고, 5배↑ 과열), 종가 위치(8: 고가 마감), 윗꼬리(7: 짧을수록) |
| 추세·위치 | 25 | 20일선 위·20>60일선·60일 고점 근접(12), 20일선 이격 ÷ ATR14(5: 2배 이하 만점, 3.5배↑ 0점), 지수 대비 20일 상대강도(8) |
| 재무 | 15 | 영업이익 흑자(6), ROE(9) — KIS 마스터 기준 |
| 뉴스 | 감점 | 악재 헤드라인 1건당 −5 (최대 −15, 철회·승소 등 해소 문맥 제외). 뉴스 없음 = 0. DART 악재 공시는 탈락 |

필터: 20일 평균 거래대금 50억↑, 5일 외국인·기관(금투 제외) 각각 순매수 + 합계 코스피 50억/코스닥 20억↑, 당일 +15%↑·5일 +30%↑ 제외.
시장 환경은 시장별 순위에 영향이 없어 점수 대신 신호등으로 표시. 기준값은 `kstock/score.py` 상단 상수 (검증 전 가설).

**Secrets**: `KIS_APP_KEY`, `KIS_APP_SECRET` (필수), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `DART_API_KEY` (선택 — 넣으면 다음 실행부터 자동 사용),
`KSTOCK_TELEGRAM_BOT_TOKEN` / `KSTOCK_TELEGRAM_CHAT_ID` (선택 — 국장 전용 봇/방. 없으면 COT 봇/방으로 전송),
`KSTOCK_CAPITAL` (선택 — 계좌 자본, 숫자만. 진입 신호에 매수 수량 표시. 공개 레포라 반드시 Secret으로)


## 웹페이지 — https://janbakbakee.github.io/woong/kstock/

종목별 60일 캔들·20일선·거래량·외인/기관 순매수 차트(인라인 SVG, JS 없음), 최근 20일 순매수 표(외인·기관·연기금·투신),
영역별 점수 막대와 세부 지표, 현재가(기준일 종가)·평균 목표가(최근 리포트 건수·기간·증권사), 10일 중 등장 횟수·첫 등장 대비 수익률,
전일 TOP에서 이탈한 종목, 네이버증권 모바일/PC 링크.

날짜 탭 끝의 **📖 지표 해설**(`guide.html`)에 지표별 의미·값 구간·점수를 정리했다. 페이지의 지표 이름(ⓘ)을 누르면
요약 설명 상자가 뜬다(HTML popover, JS 없음 — 내용은 `templates/_tips.html.j2`, '자세히 →'는 해설 탭의 해당 항목).

양식은 템플릿(`templates/day.html.j2`, 해설 `guide.html.j2`, 공통 스타일 `_style.html.j2`)에서만 정한다. 장 마감마다 보관 중인 10거래일 JSON으로 모든 탭을 다시 그리므로
양식을 고치면 과거 탭까지 같은 모양으로 바뀐다. 색은 고정값(상승 빨강·하락 파랑·흰 배경).

## 파일

| 파일 | 역할 |
|---|---|
| `main.py` | 실행 진입점: 휴장일·지수·후보 조회 → 점수 → 뉴스·공시 → 웹페이지·메시지 |
| `kis.py` | KIS Open API(토큰·투자자 일별·지수·해외지수·투자의견·휴장일·현재가·장중 가집계)와 종목 마스터 파싱 |
| `score.py` | 필터·100점 점수 (기준값은 상단 상수) |
| `signals.py` | 진입 셋업 🅐/🅑·등급·위험 기반 비중 (기준값은 상단 상수) |
| `extras.py` | Google News 헤드라인, DART 공시 (키 있을 때만) |
| `site.py`, `templates/day.html.j2` | 웹페이지 데이터 저장·10거래일 보관·차트·렌더링 |

## 실행

```
python -m kstock.main --session close --dry-run    # 전송 없이 출력 (pre = morning, intraday = 장중 예비)
python -m kstock.main --send work/kstock-20261012-close-msg.json   # 저장된 메시지만 전송
python -m kstock.main --rebuild-site       # 분석 없이 웹페이지만 다시 생성 (Actions: site_only)
python -m kstock.main --demo               # 합성 데이터로 장 전·장중·장 마감 메시지 미리보기 (Actions: demo)
```
Actions에서는 `--dry-run`으로 분석·페이지 생성 → 페이지 커밋·Pages 업로드 → `--send`로 텔레그램 전송 순서로 돈다
(링크를 눌렀을 때 새 페이지가 열리도록). 수동 실행의 `dry_run`을 켜면 커밋·전송 단계를 건너뛴다.
