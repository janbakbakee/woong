# 국내주식 수급 추천 (kstock)

COT와 별개로 돌아가는 패키지. `cot/`를 import 하지 않고, 워크플로·동시실행 그룹도 따로(`kstock-daily`) 쓴다.
텔레그램은 순위·한 줄 코멘트만, 근거(차트·수급표·점수·목표가)는 웹페이지 `docs/kstock/` (COT와 같은 GitHub Pages 사이트, 장 마감 실행만 커밋).

```
평일 07:47 KST (장 전) / 18:07 KST (장 마감)  — .github/workflows/kstock-daily.yml
 ├─ KIS 휴장일 조회 → 휴장이면 종료 (조회 실패는 휴장으로 보지 않고 실패 알림)
 ├─ 코스피·코스닥 지수 일봉 → 기준일(최신 거래일) · 시장 신호등 🟢🟡🔴 · 상대강도 기준
 ├─ KIS 종목 마스터 → 보통주·정상거래·시총(코스피 3천억/코스닥 2천억↑)·전일 거래대금 10억↑
 ├─ 종목별 투자자매매동향(일별) → 기준일 불일치 제외 → 필터 → 100점 점수
 ├─ 시장별 상위 10개: DART 악재 공시 제외 + Google News 악재 헤드라인 감점
 ├─ 조건 통과 전체 후보 CSV(top_rank 포함)·메시지 원문 → Actions 아티팩트(90일, 백테스트용)
 ├─ [장 마감] TOP 종목 증권사 투자의견·목표가(최근 3개월, KIS) → docs/kstock/data/<기준일>.json
 │           → 최근 10거래일만 남기고 날짜 탭 페이지 생성 → 커밋 → Pages 배포
 └─ 코스피 TOP 5 · 코스닥 TOP 5 → 텔레그램 2통 (페이지 커밋 뒤 전송, 장 전에는 미국 시장 한 줄)
```

| 영역 | 배점 | 내용 |
|---|---|---|
| 수급 | 35 | 기관 = 기관계 − 금융투자. 5일 외인+기관 ÷ 20일 평균 거래대금(12), 20일 누적 ÷ 시총(10, 만점: 시총 10조↑ 0.3%·2조↑ 0.6%·그 외 1%), 쌍끌이 연속 3~10일(8), 연기금·투신·사모 비중(5) |
| 거래량·캔들 | 25 | 거래량 배수(10: 1.2~3배 최고, 5배↑ 과열), 종가 위치(8: 고가 마감), 윗꼬리(7: 짧을수록) |
| 추세·위치 | 25 | 20일선 위·20>60일선·60일 고점 근접(12), 20일선 이격 ÷ ATR14(5: 2배 이하 만점, 3.5배↑ 0점), 지수 대비 20일 상대강도(8) |
| 재무 | 15 | 영업이익 흑자(6), ROE(9) — KIS 마스터 기준 |
| 뉴스 | 감점 | 악재 헤드라인 1건당 −5 (최대 −15, 철회·승소 등 해소 문맥 제외). 뉴스 없음 = 0. DART 악재 공시는 탈락 |

필터: 20일 평균 거래대금 50억↑, 5일 외국인·기관(금투 제외) 각각 순매수 + 합계 코스피 50억/코스닥 20억↑, 당일 +15%↑·5일 +30%↑ 제외.
시장 환경은 시장별 순위에 영향이 없어 점수 대신 신호등으로 표시. 기준값은 `kstock/score.py` 상단 상수 (검증 전 가설).

**Secrets**: `KIS_APP_KEY`, `KIS_APP_SECRET` (필수), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `DART_API_KEY` (선택 — 넣으면 다음 실행부터 자동 사용),
`KSTOCK_TELEGRAM_BOT_TOKEN` / `KSTOCK_TELEGRAM_CHAT_ID` (선택 — 국장 전용 봇/방. 없으면 COT 봇/방으로 전송)

로컬 실행: `python -m kstock.main --session close --dry-run` (`--session pre` = `morning`)

웹페이지: 종목별 60일 캔들·20일선·거래량·외인/기관 순매수 차트(인라인 SVG), 최근 20일 순매수 표(외인·기관·연기금·투신),
영역별 점수 막대와 세부 지표, 현재가(기준일 종가)·평균 목표가(최근 리포트 건수·기간·증권사), 10일 중 등장 횟수·첫 등장 대비 수익률,
전일 TOP에서 이탈한 종목, 네이버증권 모바일/PC 링크.
